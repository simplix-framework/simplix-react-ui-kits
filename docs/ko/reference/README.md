# 참조

이름, 키, 명령을 찾는 문서입니다. 목록만 제공하며 이유는 설명하지 않습니다.

| 문서 | 목록 |
| --- | --- |
| [`simplix-mockup` 명령](./simplix-mockup-commands.md) | mockup 패키지의 모든 명령, 인자, 종료 코드 |
| [`mockup.config.json`](./mockup-config.md) | 목업 루트 설정에 쓸 수 있는 모든 키 |
| [kit 매니페스트](./kit-manifest.md) | kit의 `package.json`에 있는 `simplix` 키와 mockup 패키지의 엔트리 |
| [워크스페이스 스크립트](./workspace-scripts.md) | 이 저장소 루트와 각 패키지의 스크립트 |

kit 파트의 공개 API는 소스의 export에 TSDoc으로 문서화되어 있습니다.

> **함께 보기:** 여기에 나열한 항목의 사용 방법은 [가이드](../guides/README.md)에 있습니다.
