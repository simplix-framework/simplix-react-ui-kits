# Reference

Look a name, a key or a command up here. These documents list; they do not explain.

| Document | Lists |
| --- | --- |
| [`simplix-mockup` Commands](./simplix-mockup-commands.md) | Every command of the mockup package, its arguments and its exit codes |
| [`mockup.config.json`](./mockup-config.md) | Every key a mockup root's configuration can hold |
| [Kit Manifest](./kit-manifest.md) | The `simplix` keys of a kit's `package.json`, and the mockup package's entries |
| [Workspace Scripts](./workspace-scripts.md) | The scripts of this repository's root and of each package |

The public API of a kit part is documented in its source, as TSDoc on the export.
