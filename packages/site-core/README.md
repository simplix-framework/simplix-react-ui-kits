# @simplix-react-ui-kits/site-core

The parts every web site design shares: behaviour and markup, each element that carries a look marked with `data-slot`. A design kit (`@simplix-react-ui-kits/site-clarity`) re-exports these segments and draws the slots; an app imports the design kit, never this package.

| Segment | Exports |
| --- | --- |
| `/help` | `SearchHero` (a band with the status line, the one h1, the lede, searches to try and the search), `StatusLine`, `SiteSearch` (a combobox whose matches open under it; the arrows move the active match and Enter opens it; `searchKeyTarget`), `CategoryGrid`, `ArticleList` (numbered rows with a badge on the heading), `SiteColumns`, and the way to ask support: `ContactPanel` (closed), `ContactForm` (the layout and its submit; the controls are the product's), `FormField`, `FieldRow`, `SuggestBox`, `AttachBox`, `ContactSent`; and the article: `ArticleIntro` (facts, where it applies, lead), `QuickBox`, `ArticleStep` (a numbered disc that ticks once the step is tried, and the tried toggle), `ArticleFigure`, `TipNote`, `DocSection`, `FeedbackPanel`, `RelatedLinks`, `DocProgress` |
| `/install` | `CheckCard` (a check of the reader's computer: idle with its action, running with a spinner, done with a chip per finding and the verdict; `checkPassed`), `DownloadGrid`, `DownloadCard` (title, needs, file, action; the highlighted one primary), `NoticeCard`, `InstallSteps` (numbered cards with a tag and a media slot), `ScreenSketch` (a drawn window with a progress bar, a pill or a code), `VideoCard` and `SiteProgress`, `DisclosureList` (questions that open one at a time to a cause, numbered steps and a `CopyBlock`), `NumberedList`, `ActionLine` |
| `/legal` | `DocLayout` (a document page: the trail, the one h1 with its badge, controls and notice, then the contents rail with ticks for tried steps and dots for changed sections, beside the sections; below the medium tier the rail spans the column and the product's jump control replaces its list), `LegalTable` (rows whose values carry their column's name on a narrow page) |
| `/link` | `SiteLinkProvider`, `SiteLink`, `useSiteLink`, `PlainSiteLink`: every site link is drawn with the router link the provider names, a plain anchor otherwise |
| `/action` | `SiteAction` (`SiteActionSpec`): a link when it opens an address, a button otherwise, and always a disabled button when disabled; `submit` makes it the form's submit button; `tone` primary, secondary or quiet, `size` md, sm or lg (a hero's), `block`, `pressed` for a toggle; a quiet action takes narrower side room for its size (`actionPad`) |
| `/shell` | `SiteWindow` (the `page` container, bar, main, footer; moves focus to the page when `page` changes), `SiteBar` (brand, page links with the current one, visitor action or signed-in account with its avatar, more menu below the narrow tier, `tone="dark"`), `SiteFooter` (owner, legal links, language picker place), `SiteBand` (a dark band), `avatarInitial`, `menuKeyTarget` |
| `/marketing` | `HeroBand` (a band with the one h1, its accent line, lede, large actions, facts line and a media slot; `tone="dark"`), `PlayerCard` (choice, sentence, wave, play row), `PlayToggle`, `ReadAlong` (`readWordState`, `readWordAt`), `SiteWave` (bars from the product's levels, the share played), `SiteBars` (a picture of bars), `SampleRow` (a sample as one toggle: disc, name, meta, text or the product's wave while playing), `SampleList`, `SplitSection` (display heading and lede beside content), `NumberedSteps` (numbered cards with a media slot and a line of promises, `stepNumber`). The kit plays no audio: the product's player hands the parts its state |
| `/page` | `SitePage` (the column; `rhythm="spaced"` under a band that holds the page's head, `"open"` for a marketing page), `SitePageHead` (eyebrow, the one h1, lede), `SiteSection` (named by its h2, `size` md or lg), `SiteBreadcrumb` (its separator a glyph the product draws), `SiteChip` (a status in a tone, with a dot), `SiteSpinner`, `SiteCaption`, `SiteLive` (a status only a screen reader reads); `SITE_CARD` and `SITE_CARD_GROUND` are the card ground other parts' styles build on |
| `/pricing` | `SwitchRow`, `SegmentedSwitch` (a radio group walked with the arrows; `switchKeyTarget`), `PlanGrid`, `PlanCard` (name, price, unit, note, pitch, detail, features, highlight, current, actions), `FeatureList`, `OfferRow`, `PriceTable`, `QuestionList` |

The parts take plain props and name no product, endpoint or router: labels, addresses and handlers come from the product. A part writes no class; its look lives in its `.style.ts` declaration (`defineSlotStyle`), which the design kit's `design:css` turns into the stylesheet. `pnpm lint` runs `simplix-design-classes` (no look class on an element), `simplix-slot-spread` and the design literal check.
