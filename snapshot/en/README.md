# Documentation

Documentation for simplix-react-ui-kits, organised by what you are doing when you open it.

| Section | You are | Contents |
| --- | --- | --- |
| [Getting Started](/en/getting-started/README.md) | New to the kits | Overview, installation, quick start |
| [Core Concepts](/en/core-concepts/README.md) | Trying to understand a design decision | Kits and designs, screen templates, mockup roots, console pages, lists, records and search |
| [Guides](/en/guides/README.md) | In the middle of a task | Use a kit, generate screens, create a mockup root, propose a framework design change, add a screen part, work on the kits, release |
| [Tutorials](/en/tutorials/README.md) | Learning by doing | Build a mockup root with one screen |
| [Reference](/en/reference/README.md) | Looking something up | `simplix-mockup` commands, `mockup.config.json`, kit manifest keys, workspace scripts |

Each document is one type: a tutorial teaches, a guide solves one problem, a reference lists, and a concept explains why. A document that needs another type links to it.

[llms.txt](en/llms.txt ':ignore') lists every document with a one-line summary for a language model.
