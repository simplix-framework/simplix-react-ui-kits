# SimpliX React UI Kits

![version](https://img.shields.io/badge/version-0.1.0--SNAPSHOT-blue)

> UI kits for simplix-react products: screen parts, screen templates and mockup tooling

- One area, several designs: a core kit and the design kits that redraw its parts
- Screens generated from the kit's templates by the simplix CLI
- Parity between the kits of an area checked by machine
- Mockups drawn in Storybook with the product's kit
