# 콘솔 레코드와 검색

레코드 상세가 그리는 항목의 이름과 순서를 정하는 방식, 그리고 콘솔의 단일 검색으로 레코드나 화면을 찾는 방식을 설명합니다.

## 레코드 상세

`RecordDetail`은 탭의 유무와 관계없이 공지를 본문 위, 헤드 아래에 그립니다. 공지는 아래에 있는 필드를 설명하므로 먼저 읽게 됩니다. 헤드 수치의 이름은 그 수치가 그리는 필드에서 가져옵니다. `contract.headFigures(fields, row)`는 contract 필드마다 `{ key, label, value }`를 반환하며, 레이블은 목록의 컬럼과 페이지의 타일이 쓰는 것과 같습니다. 그래서 값 하나는 모든 언어에서 이름이 하나이고, 화면은 이를 위한 카탈로그 키를 작성하지 않습니다. 레코드의 필드가 아닌 수치(두 필드의 비율, 미터)는 자체 레이블을 지정한 `RecordHeadFigure`로 작성합니다. 섹션의 이름은 담고 있는 필드가 아니라 헤드에 더하는 내용으로 정합니다. "값" 필드를 담은 "값" 섹션이나 헤드 수치 "비용" 아래의 "비용" 섹션은 같은 값을 두 번 그립니다.

## 콘솔 검색

콘솔의 검색은 하나이며, 라우트 화면이 아니라 셸 파트입니다. 상단 바의 검색 필드, 휴대폰 바의 검색 글리프(`ConsolePhoneShell`의 `actions`에 두는 `ConsolePhoneSearchButton`), ⌘K 또는 Ctrl+K가 모두 같은 팔레트 `ConsoleCommandPalette`를 엽니다. 이 팔레트는 `useConsoleSearch`(`/shell`)로 연결하며, `app-shell` 템플릿이 창마다 한 번 마운트합니다.

- **대상 사용자와 용도**: 이름, 코드, 화면을 알고 있어서 메뉴를 거치지 않고 해당 레코드나 화면으로 가려는 운영자.
- **입력 중 표시 순서**: 계정이 열 수 있는 이동 대상(권한 조건을 적용한 메뉴. 항목과 그룹 이름으로 일치를 찾으며 한글 초성 포함), 일치한 레코드 출처별 그룹, 동작 순입니다. 입력 전에는 최근 항목(마지막으로 연 레코드와 화면 8건, 브라우저에 계정별로 저장), 이동 대상, 동작 순입니다.
- **레코드 그룹**은 계정이 열 수 있는 목록 하나입니다(`FederatedSearchSource`). 이름, 표시, 최대 5행(제목은 인터페이스 언어로 쓰고 ID는 쓰지 않으며, 둘째 줄에는 값 1~3개를 둡니다), 같은 검색어로 목록을 여는 마지막 행(`<route>?q=<text>`. `CrudPage`가 `q`를 목록의 검색 칸에 입력)으로 구성합니다. 조회 중인 그룹은 자기 줄에 조회 중임을 표시하고, 실패한 그룹은 다른 그룹을 그대로 둔 채 자기 줄에 실패를 표시합니다. 어느 출처에도 없는 검색어는 그 검색어를 표시합니다.
- **조회 조건**: 두 글자 이상, 마지막 키 입력 후 250ms, 허용된 모든 출처에 동시 요청. 새 검색어는 signal로 이전 요청을 취소하며, 그래도 도착한 이전 응답은 버립니다. 거부된 요청, 성공이 아닌 응답 봉투, 행 목록이 아닌 본문은 해당 출처의 실패로 처리합니다. 한글 초성만으로 된 검색어는 명령만 로컬에서 찾고 출처에는 요청하지 않습니다.
- **헤더 행**은 검색 글리프, 입력 필드, Esc 키캡으로 구성하며, 패널과 같은 안쪽 여백을 두고 아래쪽 선 하나로 구분합니다. 입력 필드는 테두리와 포커스 링을 그리지 않습니다. 팔레트가 열려 있는 동안 키 입력을 받으며, 포커스 위치는 패널과 캐럿으로 나타냅니다. 결과 행에서는 선택한 행의 배경으로 키보드 위치를 표시합니다.
- **키**: 방향키로 이동, Enter로 열기, ⌘ 또는 Ctrl과 Enter로 레코드나 화면을 새 탭에서 열기, Esc로 닫기. 닫으면 팔레트를 연 컨트롤로 포커스가 돌아갑니다. 입력 필드는 listbox에 대한 combobox이고, Tab은 대화 상자 안에서만 이동합니다.
- **각 부분의 위치**: `createFederatedSearch`와 `useFederatedSearch`(`/shell`)는 엔티티를 알지 못합니다. 제품이 생성된 검색 호출로 목록마다 출처를 하나씩 선언하고, 셸의 `search` 파트가 출처, 최근 항목 키, 제품의 동작을 `useConsoleSearch`에 전달합니다.
