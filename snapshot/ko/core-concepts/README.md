| 문서 | 설명하는 내용 |

| [kit과 디자인](/ko/core-concepts/kits-and-designs.md) | 영역마다 core kit과 디자인 kit을 두는 이유, 슬롯의 뜻, 디자인 kit에 컴포넌트를 두지 않는 이유 |
| [화면 템플릿](/ko/core-concepts/screen-templates.md) | 템플릿을 core kit에 두는 이유, CLI의 템플릿 탐색 순서, kit 사이의 동등성을 유지하는 방법 |
| [목업 루트](/ko/core-concepts/mockup-roots.md) | 목업 루트의 정의, mockup 패키지에 제품 값을 두지 않는 이유, 프레임워크 디자인 변경을 두는 위치 |
| [콘솔 페이지](/ko/core-concepts/console-pages.md) | 콘솔 페이지가 파트를 그리는 순서, 대시보드 그리드, 영역 계약 |
| [콘솔 목록](/ko/core-concepts/console-lists.md) | 컬럼, 표와 카드 표시, 필터, 주소에 담는 필터, 행 동작 |
| [콘솔 레코드와 검색](/ko/core-concepts/console-records-and-search.md) | 레코드 상세와 콘솔 검색 |
